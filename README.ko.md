## 무엇을 할 수 있나요?

| 알고 싶은 것 | 사용할 기능 |
|---|---|
| 신경망의 숫자는 어떻게 계산되나요? | 1–4장: 관측 → Actor/Critic → 보상·GAE → minibatch·Adam. 뉴런을 누르면 바로 아래에서 계산을 펼칩니다. |
| 여기서 정말 처음부터 학습하나요? | 5장 → **학습 시작**. 내장 예제와 별도로 내 학습기는 무작위 I.0부터 시작합니다. |
| 다른 모터·보상·외란에서는 어떻게 되나요? | **BAM · 조건 설정**에서 시험만 변경 / 가중치를 유지하며 이어 학습 준비 / 새 학습기를 구분해 적용합니다. 학습 시작은 별도입니다. |

처음 움직이는 카트는 **실제로 미리 학습한 예제**입니다. 내 학습기가 이미 학습됐다는 뜻은 아닙니다. 저장된 계산을 재생하는 일, 고정 정책을 시험하는 일, 새 경험으로 가중치를 수정하는 일은 서로 다릅니다.

## 핵심 기능

실제 PPO와 수식에 연결된 설명을 제공합니다. Actor `5→16→2`, Critic `5→16→1`의 활성값·가중치와 업데이트 변화량을 구별합니다. 같은 경험을 유지하며 역전파, 128개 평균 gradient, Adam의 기록과 실제 수정값까지 따라갑니다.

XL330·MX64·MX106의 BAM M6 식별값과 전기·마찰식을 사용하는 구동기를 선택합니다. 바퀴·rotor 관성, 기어비, 전압 포화와 접촉 한계를 표시합니다. 위치·속도·기울기 비용을 편집하고, 외력·바람·센서 잡음·지연·모델 변화를 고정·강도 증가·성과 기반 커리큘럼으로 학습할 수 있습니다.

저속 리플레이, 고정 정책 무제한 시간 추론, 자동리셋, 독립 시험, optimizer checkpoint와 언어 전환을 지원합니다. 영어·한국어는 엔진을 따로 복사하지 않고 공유합니다.

## 처음에는 이렇게 보세요

**Actor · Critic → 뉴런 클릭 → 곱·합 → tanh → 출력 → 경험과 학습 신호 → PPO 업데이트** 순서로 같은 경험을 봅니다. 입력이 바뀌어 계산값이 달라지는 것과, 학습으로 가중치가 바뀌는 것을 구별하는 것이 먼저입니다.

처음 학습할 때는 기본 XL330·기본 환경을 유지하세요. 5장에서 학습한 뒤 **종료 · 추론**으로 정책을 고정하고 작은 4N 밀침을 줍니다. 수동 밀기는 시험이지 학습 데이터가 아닙니다. 큰 외력은 접촉 모델의 적용 범위를 벗어날 수 있으므로, 단순한 정책 실패와 구분해야 합니다.

## 범위와 주의점

목표 위치를 입력받는 교육용 CartPole이며, 수정 없는 Gymnasium benchmark나 실제 로봇에 바로 넣는 제어기가 아닙니다. BAM의 수식·식별값을 이식했지만 Python/MuJoCo나 firmware 전체를 실행하지 않습니다. 바퀴의 물리값은 출처가 있으나 외관은 재구성 메시이며 원본 STL이 아닙니다. 타이어 slip, 차체 전체 동역학, 열·전류 보호와 실물 안전 검증은 포함하지 않습니다. 모든 OOD 외란에 성공한다고 주장하지 않습니다.

사용 영상은 배포 HTML을 실제 조작한 녹화입니다. 학습 곡선을 꾸며내거나 성공한 것처럼 수정하지 않았습니다. 기존 한국어판은 `archive/ko/`에 원본 그대로 보관하며 최신 한글 실행본과 구분합니다.

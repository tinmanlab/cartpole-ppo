# CartPole PPO Studio

**막대 상단을 밀어 보고, 제어기의 반응과 실제 신경망 계산을 연결합니다.**

**[실시간 시뮬레이션 바로 실행](https://tinmanlab.github.io/cartpole-ppo/index.html?lang=ko)** · **[English viewer](https://tinmanlab.github.io/cartpole-ppo/?lang=en)** · [English README](README.md)

하나의 CartPole과 다섯 단계로 실제 물리·PPO 학습을 살펴보는 브라우저 실험실입니다. GPU·계정·API 키·학습 서버가 필요하지 않습니다. 한·영 전환은 같은 엔진의 표시만 바꾸며 실험을 초기화하지 않습니다.

## 먼저 무엇을 볼까요?

| 질문 | 조작과 확인 |
|---|---|
| 외력을 줘도 제어기가 작동하나요? | 밀기 버튼 또는 ←/→를 **누르고 있는 동안** 막대 **상단**에 수평 힘을 줍니다. 0.1 N부터 시작해 관측 → Actor 명령 → 실제 바퀴 전달력 → 반응과 제어 횟수를 봅니다. |
| 신경망은 어떻게 계산하나요? | **지금 판단의 신경망 보기**는 실제 추론을 멈춰 계산을 펼칩니다. 뉴런의 곱·합·bias·tanh를 확인합니다. 3·4단계는 명시적으로 **저장된 학습 경험**으로 전환하여 GAE·역전파·Adam을 봅니다. |
| 내가 직접 학습시킬 수 있나요? | 5단계 → **학습 시작**. 내 학습기는 화면의 사전 학습 예제와 별도로 무작위 I.0에서 시작합니다. 완료된 iteration의 정책을 고정해 추론할 수 있습니다. |
| 모터·보상·외란을 바꾸면 어떻게 되나요? | **BAM · 조건 설정**에서 시험만 변경 / 가중치 유지 후 이어 학습 준비 / 새 학습기를 선택합니다. 조건 적용과 학습 시작은 별개입니다. |

**추론과 학습은 다릅니다.** 밀고 있는 동안에도 Actor는 20 ms마다 행동을 계산합니다. 별도 학습기가 새 정책을 적용하지 않는 한 가중치는 그대로입니다. 손을 떼거나 포커스가 사라지거나 일시정지·초기화·물리 정지가 발생하면 힘이 해제됩니다. 숨겨진 규칙 기반 균형 제어기는 없습니다.

**상단 힘과 카트 힘은 다릅니다.** 상단 힘에는 회전 모멘트도 있습니다. 기존 학습 프리셋과 정량 평가는 여전히 **카트 본체 외란**입니다. 수동 상단 밀기는 시험 전용이며 학습 데이터로 들어가지 않습니다. 12 N 본체 시험 점수를 12 N 상단 시험에 옮겨 붙이지 않습니다. 강한 힘으로 넘어진 경우와 접촉·무미끄럼 모델 한계로 정지한 경우를 구분해서 표시합니다.

## 실제로 구현한 것

PPO rollout, GAE, clipped objective, entropy, 해석적 역전파, minibatch 평균, gradient 제한과 Adam을 수행합니다. Actor는 `5→16→2`, Critic은 `5→16→1`입니다. 신경망의 부호·활성값·변화량은 서로 다른 수치이지 좋고 나쁨을 뜻하는 색이 아닙니다.

XL330·MX64·MX106은 고정된 [Rhoban/BAM](https://github.com/Rhoban/bam)의 식별 파라미터와 토크·마찰식을 별도 바퀴 구동 어댑터로 연결합니다. 이상적 힘 비교 모델, 보상 계수, 물리 변동, 잡음·지연·바람·밀침, 고정·램프·성과 기반 커리큘럼, checkpoint와 실제 기록 리플레이도 제공합니다.

평면 축약 모델이며 완전한 실제 로봇은 아닙니다. 바퀴 외관은 치수 기반 재구성입니다. 접지 상실 이후의 slip, 열 보호, 하드웨어 watchdog·안전성은 검증하지 않습니다. 실시간 비율은 실측하며 모든 기기에서 보장하지 않습니다.

## 실행과 검증

위 실시간 링크는 설치 없이 실행됩니다. 저장소 소스로 오프라인 파일을 만들려면:

```bash
python src/build.py
# 생성된 index.html 또는 viewer.ko.html을 브라우저에서 엽니다.
node tools/test.js
python src/build.py --check
python tools/check_package.py
```

빌드는 Python 표준 라이브러리만 사용합니다. 생성된 HTML은 배포 산출물이며, 수정할 정본은 `src/`와 번역 메시지입니다. Pages에서도 같은 소스를 빌드·검사한 후 배포합니다.
